# data sources

keeping track of where everything comes from so i do not lose it.

- lunar regolith and simulant geotechnical properties (cohesion, friction,
  density) plus grain size: Gasteiner et al. 2026, open database on github
- grain size distributions for Earth / Moon / Mars: PlanetGSD 1.0, on figshare
- plant growth in regolith mixtures (biomass, soil pH and CEC): NASA OSD-670
- lunar mineralogy (XRD): NASA AHED

apollo 15 penetrometer numbers: the data.nasa.gov page looks empty, might already
be inside the Gasteiner database, need to check.

licenses vary. the AHED mineralogy is CC BY-NC-ND (non-commercial, no
derivatives), so check before using it in anything I share.
